# LaunchPad — публичная мультиаккаунт-версия: дорожная карта

Кастодиальный лаунчер/снайпер дропов для Robinhood Chain (chainId 4663).
Хостинг ключей на нашей стороне, вход по подписи кошелька, оплата в ETH.

## Модель оплаты
- **$2 за снайп** (за задачу). Списывается с баланса аккаунта в ETH.
  - При реверте транзакции — не списываем.
  - Если баланса < $2 — не ставим в очередь, отдаём ошибку «не хватает баланса».
  - Сгоревший остаток можно отправить на благотворительность (кнопка).
- **Лаунч — бесплатно.**
- **Pro-подписка $29.99/мес** (фикс в USD, дебет в ETH), отдельно от $2/снайп.
  - Один баланс на аккаунт; подписку можно оплатить с баланса.
- Один депозит-адрес на аккаунт.

## Тарифные лимиты (Free)
- Сканер: окно до 6 часов.
- Вотчлист: до 3 дропов.
- Трекер: до 3 кошельков.
- Whale Alert, PnL-поиск, инфлюенсеры — **только Pro** (Free не даём вовсе).

## Готово ✅
- **Аккаунты (фундамент)** — один каталог на адрес, свой конфиг; джобы/вотчлист/
  сессии/ключи изолируются автоматически (все висят на пути конфига).
- **Вход по кошельку** — challenge → подпись → сессия (7 дней); кнопка
  «sign in with wallet» в панели; `SNIPE_ADMIN_ADDRESS` даёт админ-доступ.
- **Изоляция вотчлиста/календаря** — каждый видит только свой; лимит Free = 3.
- **Профиль** — ник / аватар (NFT или URL) / twitter / **telegram** (всё
  опционально); вкладка PROFILE; тариф-бейдж. Telegram — куда слать уведомления
  трекера/алертов, когда юзер хочет их не только на сайте.
- **Слой 1 (подписант) — сделан account-aware**: демон `signerd` теперь держит
  все кейсторы и по каждому запросу выдаёт signer, привязанный к нужному
  аккаунту (свой ключ + своя политика); протокол сокета получил поле `account`,
  обратно совместимо. Осталось для полного включения: перенести запись кошельков
  (добавить/сгенерить/удалить ключи) в демон, т.к. keyless-API не может
  запечатывать ключи (см. очередь).

## Слои безопасности
- Слой 2 (политика подписи), 4 (напоминания вывести после минта), 5 (пароль
  кейстора из AWS) — **в коде готовы**. Слой 5 не включён на бою (нужны клики
  в AWS-консоли: IAM-роль + секрет).
- Слой 1 (подписант отдельным процессом через unix-сокет) — в коде готов,
  **включим вместе с изоляцией кошельков**.
- Слой 6 (Nitro Enclave) — отложен, пока не делаем.

## В работе / очередь (изоляция)
1. **Кошельки по аккаунтам** — кастодиальные ключи в своём кейсторе на юзера;
   `/api/wallets`, `/api/nfts`, funding/collect/sweep через `acting().cfgPath`.
   Включить Слой 1 здесь.
2. **Джобы/снайп по аккаунтам** — раннер должен арм/файрить джобы каждого юзера
   независимо (сейчас глобальный `jobs[]` и один армленный таймер).
3. **Депозит-адреса + баланс + леджер** — `$2/снайп`, Pro-подписка, дебет в ETH.

## Бэклог (по запросу пользователя)

### 1. Админ-панель (отдельная вкладка, видна только с админского аккаунта)
- Сколько всего лежит на кошельках юзеров на сервере (суммарный кастодиал).
- Активность: самые частые заходы, что минтят / покупают.
- PnL / прибыль; **моя** прибыль с учётом комиссии ($2 × снайпы, подписки).
- **CRM подписок**: список людей с подпиской, таймер «сколько осталось».
- Ручное управление: дать кому-то **бесплатную подписку** (напр. победителю
  гива) на срок; или **бесплатные снайпы** на время.

### 2. Трекер кошельков (Free ≤ 3, Pro — больше/безлимит)
- Вбиваешь кошельки, можешь дать никнейм.
- Уведомление на сайт / в телеграм / и туда и туда, когда отслеживаемый
  **купил / сминтил / продал** NFT.

### 3. Whale Alert (только Pro, отдельная вкладка)
- Собрать базу «китов» — кошельки с портфелем от ~$10–30k (спарсить).
- Когда **3+ кита** заходят в одну коллекцию — алерт на сайт + телеграм:
  какая коллекция, кто зашёл, сколько человек.
- Каждый следующий кит после трёх (4-й, 5-й, 6-й…) — новое уведомление.

### 4. PnL-поиск + инфлюенсеры (только Pro)
- Поиск по кошельку / аккаунту OpenSea → показать его PnL по NFT в Robinhood
  Chain (тянуть из Blockscout).
- **Инфлюенсеры** — подтверждённые юзеры, показываем их PnL, чтобы можно было
  за ними следить.
